# Workout Tracker Prototype

A responsive workout tracker dashboard prototype built with React and Vite.

## Quick start

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Open the app in your browser:
   http://localhost:3000

## Notes

- The app is designed to work well on mobile screens and desktop screens.
- The dev server is configured to bind to `0.0.0.0`, making it easier to access from your local network or browser.
- For a production build:
  npm run build

## Features in this prototype

- Workout dashboard
- Today's exercise plan
- Weekly performance chart
- Exercise progress tracking
- Recent workout history
